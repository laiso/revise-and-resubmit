# 0001: 既存の読者境界で実モデルをテストする

2026-09-20 — 採用

slob-policeが反復以外を適切に指摘するか、実モデルで確認したい。費用を抑え、判断を実装コードへ置き換えない。

既存のtestsに明示実行のテストを追加し、独立したclaude -pへ現行の読者手順を渡す。提示・記録はfeed.pyを使う。本体のアーキテクチャは変えず、起動・回収・機械的検査だけをコードにする。意味の妥当性は当初人間が確認する。まず問題文と対照文の1組から始める。

読者には期待結果を渡さない。本番と異なるモデルでの成功を本番の品質保証に使わない。読者単独の試験は、スキル探索・親からの委譲・ブラウザまで含むE2Eとは区別する。

汎用評価基盤や長い方針書は先に作らない。この記録は設計作業時にだけ参照し、評価される読者には渡さない。
